# mPDAC-transcriptomics-rep

The title of this project is "Transcriptomic Deconsctruction of Metastatic Pancreatic Ductal Adenocarcinoma". 
The goal of this study is to practically narrow-down potentially significant transcripts from metastatic pancreatic ductal adenocarcinoma, Primary PDAC, and normal pancreatic tissue samples, retrieved from public databases, to identify novel biomarkers for mPDAC.

Here, it can be observed that this is an ongoing project and the progress as of now is analyzed differentially expressed genes from one dataset, containing 182 patient samples, including primary PDAC tissue samples compared with normal pancreatic tissue samples. The results and plots of which have been provided and interpreted in Wiki.
